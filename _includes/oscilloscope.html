Analog Oscilloscope

This project is THE project that has made me feel the most pride and joy. When I came up with this idea, I actually had no idea that there was common terminology for an oscilloscope like this. It started when I came across this comparator ladder posted by user TitaniumNation on the EveryCircuit webpage. I thought this was just so neat that I had to replicate it.

I started by recreating the circuit from EveryCircuit into Multisim.

It was about this time I realized that I could set two of these comparator ladders against eachother. If one ladder contained a time base and the other the input, they could be ANDed and display the function over time.

I wanted to keep this project mostly analog, which meant that I was going to avoid using integrated circuits as much as possible. At the time, I had minimal experience with MOSFET logic, and functioned best when working with NMOS transistors. So, I devised that I needed 128 NMOS transistors (2 for each AND gate) in order to create an 8x8 LED matrix to use as a display.

This is one of the eight rows that would be needed to create the entire design:

The top row of transistors (Q2,Q4,Q6...) take a single output from either comparator ladder. For me, it is the input signal that we want to observe. It could be either the horizontal or the vertical axis, the only difference is a 90° rotation on the display.

The other row has to contain every output from the other comparator ladder. This is done with Q1 being the first output, Q2 being the second, and so on.

Now, this is repeated for all seven other rows. The bottom row of transistors connects to the bottom transistor in the row above it, and the next vertical connection is shared across the next row.

Here is what it looks like with two rows of LEDs.

Here is where I encountered a massive problem though. This would never look like an oscilloscope. Its output would only ever look like a very large rendition of TitaniumNation's comparator ladder. In each row if the previous logic was high, it was going to stay high. Thus, I had to devise a way to incorporate XORs at the end of each comparator ladder output to prevent linear growth on the display.

Each two input XOR would take seven more NMOS transistors, and I needed sixteen XORs, because each input needed to be compared to the previous. Adding over 100 transistors to the project was simply not feasable and I had to use integrated circuits. This made life a quite a bit easier though.

Now that everything was simulated and working, I was able to finally begin work on constructing this project. I began with the comparator ladders, each of which used 4x LM293P dual comparator integrated circuits, 9x 1k Ω resistors, and 8x 10k Ω resistors as pull up resistors.

Then, I needed to connect each output of the comparator ladders (blue and white outside wires) to each XOR input.

Unfortunately, the only image of the white side logic contains the messy wiring, but the logic is the same as shown on the left. It takes eight inputs, four on the left four on the right of each set and performs the logic shown earlier.

From this point, wires were attached at each XOR output and connected to the LED matrix.

128x BS170 NMOS Transistors, 64x 200Ω resistors, 64x Red LEDs, a few 10M Ω resistors thrown in to pull down the transistors, HOURS of clean wiring later. I was able to connect each XOR output to a row/column and visualize signals.

In all truth, it did not work first try (shocker). I was incorrect in one of my intial thoughts that if I had a very high frequency time base, the signal would be more clear because its only connecting at the specific points for less time. Well, that just made a mess of LEDs across my breadboard. I was quickly able to piece together that for this project the two signals needed to share the same frequency.
